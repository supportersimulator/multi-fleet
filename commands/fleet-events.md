# fleet-events

Monitor realtime fleet activity. Routes to the `fleet-events` skill for EventBus subscriptions, probe findings, and fleet state snapshots.

## Examples
- `fleet-events` — show current event stream status
- `fleet-events subscribe` — connect to WebSocket event stream
- `fleet-events probe` — run probes and emit findings to EventBus
